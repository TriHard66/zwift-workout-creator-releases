# Zwift Workout Creator: downloads

Release files for Zwift Workout Creator, a personal Windows app for building Zwift workouts.
The app checks this repository for updates and only installs releases signed with the owner's key.

To install manually, download `ZwiftWorkoutCreator.exe` from the latest release.
